Pokémon Guess v7

このフォルダは、これまでの仕様をもとに作成したブラウザ向けプロトタイプです。
画面タイトル「Pokémon Guess」以外の表示は日本語で統一しています。

【起動方法】
1. インターネットに接続した状態で index.html をダブルクリックします。
2. ブラウザでモード選択画面が開きます。
3. ブラウザの制限で外部データを取得できない場合は、下記の簡易サーバー方式を使ってください。

【簡易サーバー方式】
WindowsでPythonが使える場合、フォルダ内でコマンドプロンプトを開き、次を実行します。
python -m http.server 8000

その後、ブラウザで次を開きます。
http://localhost:8000

【通常モード】
・フリー：質問、ヒント、同じ項目の使用回数すべて制限なし
・かんたん：質問20回、ヒント3回、同じ項目は制限なし
・ふつう：質問15回、ヒント2回、同じ項目は制限なし
・むずかしい：質問12回、ヒント1回、同じ項目3回まで
・エキスパート：質問10回、ヒントなし、同じ項目3回まで
・難易度に応じたスコアを結果画面に表示
・フリーのスコアは参考記録扱い

【デイリーチャレンジ】
・日本時間0:00で更新
・日付から決めた全ユーザー共通のポケモンを出題
・原種のみを対象にする
・御三家、伝説、幻、準伝説も対象に含む
・質問15回、ヒント1回、同じ項目の使用制限なし
・終了後は同じブラウザではその日の再挑戦不可
・結果は「○/15問」で表示
・ヒント回数、誤答回数、連続正解日数を表示
・答えを含まない共有用結果をコピー可能
・プレイ日数、正解率、最少質問数、最高連続正解を保存
・結果画面の「モード選択へ」は1つだけ表示

【入力制限モード】
・開始前に、今回使用できる質問項目をユーザーがチェックして選択
・1項目以上の選択が必要
・質問回数、ヒント、同じ項目の使用回数は制限なし
・選べる項目：登場した世代、種族値、高さ、重さ、名前の文字数、技、特性
・選んだ項目だけがゲーム中の質問項目に表示される

【カスタムモード】
・全質問項目をチェックボックスで使用可／使用不可に設定可能
・質問回数上限
・ヒント回数上限
・同じ質問項目の使用上限
・1回の質問で使える条件数
・最終回答回数上限
・質問履歴の初期表示
・「かつ／または」の使用可否
を設定可能
・数値0は制限なし

【種族値の扱い】
・質問項目は「種族値」1つに統合
・種族値を選ぶと、HP、こうげき、ぼうぎょ、とくこう、とくぼう、すばやさ、合計種族値から選択可能
・合計種族値は別の質問項目としては表示しない

【共通ルール】
・1回の質問に追加できる条件は、すべて同じ質問項目に限る
・例：HP80以上 かつ HP100未満 は可能
・例：HP80以上 かつ 第5世代より前 は同時には設定不可
・ポケモン名の不正解は質問1回として数える
・正解した最終回答は質問回数に含めない
・質問回数を使い切った後は質問できず、最終回答のみ可能

【既存の質問項目】
・登場した世代
・種族値（HP、こうげき、ぼうぎょ、とくこう、とくぼう、すばやさ、合計種族値）
・進化の段階
・名前の文字数
・高さ、重さ
・タイプ
・弱点
・特性
・覚える技
・タマゴグループ
・メガシンカ
・特殊な項目（御三家、伝説、幻、準伝説、600族、ウルトラビースト、リージョンフォームなど）

【入力候補】
技名、特性名、ポケモン名は文字入力中に候補を表示します。
カタカナ名をひらがなで入力しても検索できます。

【ヒント】
まだ質問していない通常項目からランダムに、そのポケモンに合う情報を表示します。
特殊な項目はヒント対象外です。
種族値がヒントに選ばれた場合は、6能力または合計種族値から1つを表示します。
モードや難易度ごとに使用できる回数が変わります。

【答え合わせ】
正解、降参、失敗時にポケモン画像を表示します。
そのゲームで実際に質問した項目だけ、答えのポケモンの実データを表示します。

【ゲーム履歴】
終了したゲームを最大30件、ブラウザのlocalStorageに保存します。
日時、モード、結果、答え、質問回数、質問内容と回答を確認できます。

【ゲームデータについて】
ポケモンの基本情報、技、特性、進化系統などはブラウザからPokéAPIを取得して判定します。
弱点はタイプ相性だけで計算し、特性による相性変更は含めません。
